How Prefix Rules Work

Prefix Rules use verified Hollander/IPN prefixes to confirm or disambiguate part identity. A prefix meaning is used only when that prefix is verified. Unlisted prefixes are never guessed and are not automatically errors when another authoritative source establishes the part.

Prefix Rules do not replace Source Priority or Category Rules. No runtime title logic is implemented in this tab.
