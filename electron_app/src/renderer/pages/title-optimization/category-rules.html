How Category Rules Work

Category Rules tell the title optimizer which verified details matter most for a specific part type. They never create missing information. A detail should only be used when it is available from an approved source and is relevant to the listing.

Category Rules do not override Source Priority, Prefix Rules, Restricted Terms, or verified fitment requirements. No runtime title logic is implemented in this tab.
