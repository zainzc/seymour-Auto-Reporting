# Synonyms Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the approved Synonyms configuration tab to the existing Title Optimization workspace.

**Architecture:** Follow the Terminology service/repository/IPC/preload/renderer boundaries. Keep ten mapped rules separate from the CV Axle policy. Use one persisted Synonyms configuration for the master toggle and rules.

**Tech Stack:** Electron 40, CommonJS, HTML/CSS/vanilla JavaScript, encrypted electron-store, Node test runner.

**Spec:** `docs/superpowers/specs/2026-09-17-synonyms-design.md`

## Global Constraints

- Seed exactly ten normal mappings; CV Axle is policy only, with condition `confirmed-front-half-shaft` and the approved note.
- True first run is `getStored() === undefined`; never repair or reseed malformed saved data automatically.
- Pop-up Add/Edit only; no sidebar or permanent editor; Priority/origin stay internal.
- No title generation, AI, Airtable, fitment validation, or publishing.
- Master/row toggles save immediately with rollback on error; Add/Edit saves explicitly.
